# hackathon-2026

## Frontend (Next.js)

Cała aplikacja znajduje się w katalogu **`frontend`**.

Pełna instrukcja: **krok po kroku od `git clone` do uruchomienia na localhost**, wymagania (Node.js), skrypty i opcjonalny fork — jest w pliku:

**[frontend/README.md](frontend/README.md)**

Skrót:

```bash
git clone https://github.com/<user>/hackathon-2026.git
cd hackathon-2026/frontend
npm install
npm run dev
```

Potem otwórz [http://localhost:3000](http://localhost:3000).
